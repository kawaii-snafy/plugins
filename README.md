# kawaii-snafy plugins

Личный маркетплейс плагинов для [Claude Code](https://code.claude.com).

## Установка

```
/plugin marketplace add kawaii-snafy/plugins
/plugin install <плагин>@kawaii-snafy
```

## Плагины

- **files** — панель `/files`: дерево рабочей папки (следует за worktree) с git-пометками, режим «Изменения», просмотр файла или его git diff; на широкой панели список всегда справа, просмотрщик слева. Пути в ответах агента кликабельны: клик открывает файл в панели. Справа в нижней строке — ветка, worktree и сводка изменений (+/− цветом); клик по ней открывает «Изменения».
